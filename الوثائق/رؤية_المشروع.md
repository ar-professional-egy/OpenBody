# OpenBody

منصة ذكية مفتوحة المصدر لتحليل أضرار السيارات وإدارة عمليات الإصلاح باستخدام الذكاء الاصطناعي

## الرؤية (Vision)

إنشاء أول منصة عربية وعالمية مفتوحة المصدر تستطيع تحليل أضرار السيارات من الصور باستخدام الذكاء الاصطناعي، وتقديم تقرير احترافي يوضح:
- مكان الضرر.
- نوع الضرر.
- مستوى الضرر.
- القطع المتضررة.
- طريقة الإصلاح.
- التكلفة التقديرية.
- مدة الإصلاح.
- نسبة الثقة.
- تقرير قابل للمشاركة.

## أهداف المشروع

### للمستخدم
- تصوير السيارة.
- معرفة حجم الضرر.
- معرفة تكلفة الإصلاح.
- مقارنة الأسعار.
- حفظ جميع التقارير.

### للورش
- استقبال السيارات.
- إنشاء تقارير تلقائياً.
- إدارة الإصلاحات.
- إصدار عروض الأسعار.
- متابعة مراحل الإصلاح.

### لشركات التأمين
- تحليل المطالبات.
- كشف الاحتيال.
- مقارنة الأضرار.
- تسريع الموافقات.
- تقليل التكاليف.

### للوكلاء
- تقييم السيارات.
- فحص السيارات المستعملة.
- متابعة الضمان.
- إدارة مراكز الخدمة.

## مكونات النظام

### 1. تطبيق الهاتف
- Flutter
- يعمل على Android و iOS

**الوظائف:**
- تسجيل الدخول.
- التقاط الصور.
- رفع الصور.
- متابعة التحليل.
- مشاهدة النتائج.
- مشاركة التقرير.
- إدارة الحساب.

### 2. الموقع الإلكتروني
- واجهة ويب (React / Vite)
- **تشمل:**
  - الصفحة الرئيسية.
  - معلومات المشروع.
  - لوحة العميل.
  - لوحة الورشة.
  - لوحة الإدارة.
  - الوثائق.
  - API.

### 3. الخادم
- FastAPI
- **يتولى:**
  - إدارة المستخدمين.
  - إدارة الصور.
  - تشغيل الذكاء الاصطناعي.
  - إنشاء التقارير.
  - الإشعارات.
  - إدارة الملفات.

### 4. الذكاء الاصطناعي
- يتكون من عدة نماذج.
- **تحليل الصور:**
  - كشف السيارة.
  - تقسيم الأجزاء.
  - كشف الضرر.
  - تصنيف الضرر.
  - تقدير الشدة.
- **تقدير التكلفة يعتمد على:**
  - القطعة.
  - نوع الضرر.
  - ساعات العمل.
  - سعر القطعة.
  - سعر الدهان.
  - سعر الورشة.

## أجزاء السيارة
- يشمل تقريبًا جميع الأجزاء الخارجية: الصدام الأمامي، الصدام الخلفي، الكبوت، السقف، الأبواب، الرفارف، الشنطة، المصابيح، الزجاج، المرايا، الشبك، وغيرها.

## دورة العمل
تصوير السيارة ➔ رفع الصور ➔ تحسين الجودة ➔ كشف السيارة ➔ تقسيم الأجزاء ➔ كشف الأضرار ➔ تصنيف الضرر ➔ تقدير التكلفة ➔ إنشاء التقرير ➔ حفظ التقرير ➔ مشاركة التقرير

## قاعدة البيانات
- تشمل: المستخدمين، السيارات، الصور، التقارير، الأضرار، الأسعار، الورش، شركات التأمين، الإشعارات، النسخ الاحتياطية.

## لوحة الإدارة
- تسمح بـ: إدارة المستخدمين، الورش، الأسعار، مراقبة الذكاء الاصطناعي، مراجعة التقارير، الإحصائيات، السجلات.

## الذكاء الاصطناعي المتقدم
- يشمل: التعلم المستمر، إعادة التدريب، اكتشاف انحراف النماذج، تفسير النتائج (Explainable AI)، تقييم النماذج، إدارة الإصدارات.

## الأمان
- يشمل: تشفير البيانات، OAuth، JWT، سجل تدقيق، نسخ احتياطي، كشف الهجمات، إدارة الصلاحيات.

## البنية السحابية
- GitHub لإدارة الكود.
- Supabase لقاعدة البيانات والمصادقة والتخزين (أو Firebase حسب المتاح).
- FastAPI للخدمات الخلفية.
- Flutter للتطبيق.
- Docker للحاويات.
- GitHub Actions للبناء والاختبارات.
- Cloudflare Pages للموقع.
- مزود سحابي لتشغيل الخادم عند الإطلاق.

## مراحل التطوير
- **V1:** تحليل الصور، تقدير التكلفة، التقارير.
- **V2:** إدارة الورش وشركات التأمين.
- **V3:** منصة SaaS متعددة المؤسسات.
- **V4:** إدارة دورة حياة النماذج (MLOps) والتعلم المستمر.
- **V5:** منصة عالمية مع واجهات API للشركاء، وتوصيات ذكية، وتوأم رقمي للمركبات.

## القيمة المضافة
ما يميز OpenBody ليس فقط تحليل الصور، بل جمع عدة وظائف في منصة واحدة:
- تحليل أضرار السيارات بالذكاء الاصطناعي.
- إدارة عمليات الإصلاح.
- دعم الورش ومراكز الخدمة.
- التكامل مع شركات التأمين.
- إصدار تقارير احترافية.
- قابلية التوسع إلى منصة عالمية متعددة الخدمات.

# 💻 دليل المطور - OpenBody

## 🏛️ البنية التحتية
- **التطبيق (Flutter):** واجهات المستخدم، التصوير، وإرسال الطلبات.
- **الخادم (Python/FastAPI):** محرك الذكاء الاصطناعي، إدارة الطلبات، والتقارير.
- **الذكاء الاصطناعي:** 5 طبقات متكاملة (YOLO, SAM2, HF).
- **قواعد البيانات:** Supabase للمزامنة، Local Storage للعمل دون اتصال.

## 🚀 التشغيل المحلي
### الخادم
```bash
cd الخادم
pip install -r المتطلبات.txt
python الرئيسي.py
```

### التطبيق
```bash
cd التطبيق
flutter run
```

## 🧠 هيكل الذكاء الاصطناعي
1. `محسن_الصور`: تحضير الصورة باستخدام Real-ESRGAN.
2. `مقسم_الاجزاء`: تقسيم أجزاء السيارة بـ SAM2.
3. `دمج_الكواشف`: كشف الأضرار بـ YOLOv8s & YOLO11m.
4. `تصنيف_الضرر`: تحديد مستوى الضرر بـ HF Models.
5. `تقدير_التكلفة`: دمج النتائج وحساب التكلفة التقديرية.

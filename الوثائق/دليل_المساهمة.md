# 🤝 دليل المساهمة - OpenBody

نرحب بجميع المساهمات! سواء كنت مبرمجاً، مصمماً، أو خبيراً في السيارات.

## 🌟 كيف يمكنك المساهمة؟
1. **تطوير الكود:** حل المشاكل (Issues) أو إضافة ميزات جديدة (Pull Requests).
2. **تدريب النماذج:** المساهمة بصور للأضرار لتحسين دقة الذكاء الاصطناعي.
3. **التصميم:** تحسين تجربة المستخدم (UX) وواجهات التطبيق (UI).
4. **التوثيق:** ترجمة وتحديث الوثائق.
5. **التقارير:** الإبلاغ عن الأخطاء وتقديم اقتراحات.

## 📝 خطوات المساهمة في الكود
1. Fork للمستودع.
2. أنشئ فرعاً جديداً (`git checkout -b feature/AmazingFeature`).
3. قم بعمل Commit للتغييرات (`git commit -m 'Add some AmazingFeature'`).
4. ارفع الفرع (`git push origin feature/AmazingFeature`).
5. افتح Pull Request.

شكراً لمساهمتك في جعل OpenBody الأفضل! ❤️

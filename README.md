# OpenBody

OpenBody is an open-source AI-powered platform for vehicle body damage analysis, repair cost estimation, and professional report generation.

## Features

- AI-based vehicle damage detection
- Automatic repair cost estimation
- Vehicle part identification
- Professional PDF reports
- Before & After comparison
- Multi-language support (Arabic / English)
- WhatsApp report sharing
- QR Code sharing
- Cloud synchronization
- Flutter mobile application
- FastAPI backend
- Supabase integration
- GitHub Actions CI/CD
- Docker support
